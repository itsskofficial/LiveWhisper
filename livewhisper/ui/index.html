AI

Where the work happens: on this PC, private and offline, or online on Groq, which is faster on a slow computer.

Online
Speech, formatting and writing run on Groq. If you're offline or Groq is busy, this PC takes over. Languages with an accuracy model downloaded still run here, because they're far more accurate that way.
Groq API key
Free at console.groq.com. Needed for Online. Stored on this PC.
